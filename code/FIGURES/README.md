# SEJ manuscript figures — shared labels, constants, and saving

This folder contains **your 11 uploaded Python scripts** (including the shared
`B25data_processing.py`), refactored to use a central directory configuration.
The `originals/` folder contains untouched copies of all uploads for comparison.
The `tests/` folder contains checks of shared values against those originals
and verifies that all plot saves use the central helper.
The actual scientific methods and input arrays remain in your plotting scripts.
**This package reads existing projections; it does not rerun or resample them.**

## Install without overwriting your existing FIGURES folder

Extract this entire folder into something like
`/Users/ed881/Documents/GitHub/ice-sheet-sej-2025/code/FIGURES_refactored/`.
Keep the `plotting/` folder immediately next to `RUN_FIGURES.py`. Do not copy
only the runner into your old `FIGURES` folder without also copying `plotting/`.
Back up your current scripts first; your original versions are also in
`originals/` here. The runner does **not** write to `code/FIGURES` or overwrite
original projection outputs.

Install dependencies in the Python environment you use for your figures:

```bash
python -m pip install -r requirements.txt
```

## Set paths ONCE

Open `RUN_FIGURES.py` and edit the **USER SETTINGS** section:

- `PROJECT_DIR`: root `ice-sheet-sej-2025` directory.
- `DATA_DIR`: CSV, XLS/XLSX inputs, which can be outside the project.
- `UPSTREAM_OUTPUT_DIR`: **existing** Method B/C2200-boundary model outputs.
- `FIGURE_OUTPUT_DIR`: **new** figure destination, e.g. `output/manuscript_figures`.
- `B25_MONTE_CARLO_FILE`, `B19_SUMMARY_FILE`, `B19_ADJUSTED_FILE`,
  `EXPERT_QUESTIONS_FILE`, `EXPERT_WORKBOOK_FILE`, `PERFORMANCE_FILE`,
  `AR6_WORKBOOK_FILE`, `COUPLED_SEJ_FILE`: explicit input files.
- `CMIP6_ANNUAL_DIR`, `CMIP7_ANNUAL_DIR`, `CMIP6_SELECTION_FILE`,
  `CMIP7_SELECTION_FILE`: exact precomputed **Method B, [2100,2200]
  checkpoints, C2200 hard-boundary** inputs. These are not generated by the
  plotting scripts. They can be independently set to absolute paths if needed.

**Important:** Your original `split_violin_plot_adjustedB19_B25.py` reads the
baseline-adjusted B19 workbook from a Downloads folder. The default here is
`DATA_DIR/B19_process_and_total_MC_adjusted_to_B25_baseline.xlsx`. If you
haven't moved it, set `B19_ADJUSTED_FILE` to its actual Downloads path instead.

For a new machine you can also use `--project-dir`, `--data-dir`,
`--upstream-dir`, and `--output-dir` in Terminal. CLI root overrides assume
conventional filenames underneath those roots; edit the file-specific settings
if your input filenames or folder hierarchy differ.

## Run it

From Terminal (in the extracted folder):

```bash
python RUN_FIGURES.py --list
python RUN_FIGURES.py --check
python RUN_FIGURES.py
```

Or open `RUN_FIGURES.py` in Spyder and press **F5**. The defaults regenerate
all groups. To regenerate only specific figure families:

```bash
python RUN_FIGURES.py --only annual_trajectories cmip_panels
python RUN_FIGURES.py --only warming clustered b19_densities
python RUN_FIGURES.py --skip b19_violins --continue-on-error
```

The command `--check` reports missing inputs **without plotting or creating
figure directories**. The default run checks selected inputs first; if any are
missing, it stops rather than silently plotting a different method. With
`--continue-on-error`, independent groups with valid inputs can still run.
A manifest is saved in `FIGURE_OUTPUT_DIR/run_manifest.json` recording statuses,
input paths and configuration. It does not verify pixel-for-pixel equivalence
with your earlier PNG files; see validation below.

Set `SHOW_FIGURES=True` in the USER SETTINGS section only when using an
interactive matplotlib backend if you want display windows. The batch default
is save-only (`Agg`), avoiding `FigureCanvasAgg ... cannot be shown` warnings.
Set `INCLUDE_UNSCALED_DRIVERS=True` to additionally generate the per-warming
unscaled SMB and ocean driver figures that were commented out in the original.

## What changed and what was deliberately NOT changed

- One shared `figure_settings.py` routes data files, precomputed model outputs,
  and figure destinations. All ten figure scripts use it.
- The new `plotting/figure_style.py` is the single home for color palettes and
  named color roles. All ten figure scripts import their colors from it; the
  original hues have been retained rather than replaced by a new theme.
- `figure_helpers.py` centralizes B25 sample extraction, PNG saving,
  and the save-only/interactive display behavior. `B25data_processing.py` remains the
  shared B25 parsing/reshaping/derived-total module.
- The runner executes each plotting script in its **own subprocess**, so the
  scripts can retain their existing global plotting settings and avoid leaking
  state into one another. This is less memory-efficient than loading all
  50,000-draw data into one process, but avoids retaining multiple huge arrays
  and makes individual scripts independently runnable.
- The annual-trajectory script's five original figure switches are all enabled
  when that group runs, so it produces warming, grid, AR6, SSP and correlation
  figures rather than just AR6 plots. The driver script defaults to the one
  active combined scaled plot in the uploaded version; additional formerly
  commented-out figures are opt-in as described above.
- In the performance plot only, spreadsheet year codes 2019/2026 are mapped to
  elicitation-year labels 2018/2025 before plotting; rows already coded 2018
  and 2025 remain unchanged.
- Existing methods, quantiles, color choices, axes, original observational
  rebasing, and joint-draw AIS/total calculations are not intentionally
  modified. The **CMIP7 C2200-boundary files are required**; this package does
  not create missing CMIP7 boundary outputs or substitute no-boundary runs.

## Changing figure colors in one place

Open `plotting/figure_style.py` to adjust the manuscript-wide palette. For
example, change `ICE_SHEET_COLORS["WAIS"]` (defined using `ORANGE`) to affect
WAIS consistently in the density, violin, annual-trajectory, and CMIP-panel
plots. Warming colors live in `WARMING_COLORS`; climate pathways in
`CLIMATE_SCENARIO_COLORS`; driver responses in `DRIVER_RESPONSE_COLORS`;
performance years in `PERFORMANCE_YEAR_COLORS`.

The AR6 comparison greys and percentile-difference line styles are deliberately
separate, as are the expert-judgment role colors. The existing standalone total
ice-sheet trajectories and CMIP panels used slightly different neutral grays;
both have been kept so this purely organizational refactor does not change the
figures unexpectedly. All 6-digit hexadecimal color literals in the *refactored
plotting code* now live in `figure_style.py`. Unchanged original scripts remain
in `originals/` as a reference.

Potential future work: consolidate observational/annual-NetCDF readers while
preserving joint-draw statistics, and visually compare the regenerated PNGs to
accepted manuscript figures before editing any figure-specific axes or methods.

## Shared labels and scientific constants

Use `plotting/figure_labels.py` for common component names, process labels,
warming and CMIP scenario identifiers, time-point orders, and the existing
5/17/50/83/95 percentile levels. It also holds mm-to-cm and m-to-cm factors,
the hardcoded reference warming curves, and the C2100/C2200 reference cumulative
warming values used to annotate the **already-generated** scenario assignments.
These are *scientific assumptions*, not general cosmetic settings; only change
them after checking the actual analysis and original results. Warming labels
retain both the compact `2°C` and decimal `2.0°C` forms where previously used.
The two distinct totals (Antarctic versus all ice sheets) remain separate.

## One shared figure-saving function

All active figure saves now use `save_figure(fig, path, *, dpi=None,
bbox_inches="tight", show=False, close=False)` from `plotting/figure_helpers.py`.
It creates destination directories and uses the configured PNG DPI (300 by
default). `bbox_inches=None` is used for the performance figure to retain its
original non-tight bounding box. Individual scripts keep their original
interactive-display / closing sequence; for a new figure, you may set
`show=True, close=True` in the helper call. The helper rejects non-PNG output
paths, and never changes plotting data or global matplotlib style.

## Check the shared definitions

Run `python -m unittest discover -s tests -v` from the package root to
compare shared constants/labels against the original scripts and verify PNG
saving. These tests do **not** require the project datasets.

## Validation before manuscript submission

The uploaded files included only Python scripts, not their underlying CSV,
XLS/XLSX and NetCDF data. The package is syntax-checked, and its no-input
warm-up plot can be smoke-tested, but full figure generation and numerical/
visual comparison against your existing manuscript figures must be performed
on your computer after pointing it at the correct inputs. Compare regenerated
PNG files, the annual trajectories' correlation CSV, and the tabular driver
weights with the original outputs before replacing manuscript files.

The synthetic regression fixture used during refactoring had two extra B19
summary columns (`0.05` and `0.95`) that conflict with existing `5%`/`95%`
columns after header normalization. That test alone fails in both the prior
package and this one; the manuscript input workbook was not supplied. This
refactor deliberately does not change the original B19 input-parsing method.
